# 🌾 Agro Forte - Concurso Agrinho 2026

## Sobre o Projeto

**Agro Forte** é um site completo e moderno desenvolvido para o **Concurso Agrinho 2026**, com o tema:

> **"Sustentabilidade, Tecnologia e Desenvolvimento em Itambaracá - Paraná"**

O projeto demonstra a importância do agronegócio para o município de Itambaracá, destacando sustentabilidade, tecnologia, recursos hídricos e a conexão vital entre o campo e a cidade.

---

## 🎯 Objetivo

Criar um site profissional, responsivo e visualmente atrativo que:
- Mostre a importância econômica e social do agronegócio
- Valorize os produtores rurais e suas contribuições
- Apresente práticas sustentáveis e tecnológicas
- Destaque os recursos hídricos locais
- Demonstre o impacto positivo da agricultura na comunidade

## 🔧 Customização

### Alterar Cores
Edite as variáveis CSS em `css/style.css`:
```css
:root {
    --verde: #2E7D32;
    --azul: #1565C0;
    --bege: #F5F5DC;
    --branco: #FFFFFF;
}
```

### Adicionar Imagens
Substitua as URLs `via.placeholder.com` pelos links das suas imagens na galeria

### Atualizar Cotações
Modifique a função `atualizarCotacoes()` em `js/script.js` para integrar uma API real
